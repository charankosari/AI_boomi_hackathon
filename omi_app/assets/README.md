# Assets Directory

This directory should contain the following image assets for the Expo app:

- `icon.png` - App icon (1024x1024 px)
- `splash.png` - Splash screen image (1284x2778 px)
- `adaptive-icon.png` - Android adaptive icon (1024x1024 px)
- `favicon.png` - Web favicon (48x48 px)

For now, these can be placeholder images. The app will function without them in development mode.

To add proper assets:
1. Create the images at the specified dimensions
2. Place them in this directory
3. Update app.json if needed
